# Miami Condo Kings

Лендинг агенства недвижимости, сверстанный по макету.

## Демо:** https://antonsorok.github.io/Project_1/

![Screenshot](assets/screenshot.png)  

## Что реализовано в проекте:

- Семантическая верстка HTML5.
- Модульная сетка на 12 блоков.
- Полноэкранное меню с плавной анимацией.
- Якоря из меню, плавное перемещение по пунктам из меню.

## Стек

HTML5, CSS3 (Flexbox, Grid), JavaScript (ES6+)

## Запуск

git clone https://github.com/AntonSorok/Project_1.git

Открывается файл index.html в браузере.
